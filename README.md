TennoStore
Proyecto Full Stack para la venta de videojuegos, especializado en seguimiento de precios y reservas inteligente de stack

## TECNOLOGIAS ##
  -Frontend: React + Vote
  -Backend: Node.js + Express(API REST)
  -Base de datos: PostgreSQL
  -Despliegue: Docker + Docker Compose

## EJECUCIÓN DEL PROYECTO ##
1.-Clonación del repositorio
  git clone https://github.com/GGarno0/TennoStore
  cd TennoStore

2.Ejecución de los contenedores
  docker-compose up -d --build

3.-Visualización
  http://localhost

### Estructura ##
  /Fronted: Intefaz de usuario
  /Backend: Api y lógica de negocio
  /docker: Configuración de servicios y persistencia de datos
